# Esp32_C3_Mini-Remotexy
Es el codigo para un esp32 C3 mini, la cual se conecta atravez de Bluetooth con la App de RemoteXY para un mando para un carrito/robot que juega futbol, y se conecta atravez de comunicacion UART con la Tiva la cual lleva el proceso de control con ayuda del Driver o shlid puente H L293D
